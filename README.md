# CUTLINE. — BARBER CULTURE

**Funkční demonstrace barbershop webu.** Fiktivní značka určená pro portfolio. Nejde o skutečnou provozovnu ani systém rezervací.

## Co projekt obsahuje
- `index.html` — struktura stránky
- `styles.css` — kompletní responzivní design a animace
- `app.js` — galerie, filtry, ceník, mobilní menu a demo rezervace
- `assets/images/` — 23 skutečných fotografií z Pexels ve formátu WebP, optimalizovaných pro web
- `FOTO-ZDROJE.txt` — odkazy na zdroje fotografií a informace o licenci
- `NAHLED.jpg` — snímek první obrazovky pro rychlé zobrazení

## Spuštění
1. Rozbal ZIP.
2. Otevři `index.html` v prohlížeči. Funguje i lokálně bez serveru.
3. Pro GitHub Pages nahraj **všechny soubory včetně složky assets/images** do kořene repozitáře.
4. V nastavení repo zapni `Settings → Pages → Deploy from a branch → main / root`.

## Úpravy
- Jméno, nadpisy a texty změň v `index.html`.
- Barevné proměnné změň na začátku `styles.css`.
- Ceník se upravuje v poli `SERVICES` v `app.js`.
- Galerie se generuje z pole `PHOTOS` v `app.js`; nové fotografie přidej do `assets/images` a vlož do pole jejich cestu, název a kategorii.
- Kategorie fotek: `střih`, `interier`, `detail`.

## Důležitá poznámka
Rezervační formulář **neodesílá žádné údaje a nerezervuje termíny**. Pouze připraví textové shrnutí ke kopírování. Ceny a termíny jsou ilustrační.
